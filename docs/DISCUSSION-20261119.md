待讨论，不代表获批实施：
1. 交互底层：统一目标检测、对象名称、默认动作、条件和反馈。E 默认执行，长按是否显示次级动作待决定。
2. 塞尔达借鉴：靠近即读懂的场景提示、直接操控。僵尸毁灭工程借鉴：容器、重量、动作耗时与物品用途。避免一开始堆满右键菜单。
3. 背包：先明确物品在世界中的用途，再决定随身快捷位、携带容器、重量/体积或实体空间；用户不喜欢现有背包，需明确具体反感点再做原型。
4. 风格场景生成器：共享地形/水体/建筑/植被/镜头接口，风格包控制形态、色板、布局、天空、光照与构图。乡野童话侧重有机建筑和生活痕迹；青春动画侧重天空层次、逆光、城市细节与天气。先做单个小场景验证再抽规则，不能只换滤镜。

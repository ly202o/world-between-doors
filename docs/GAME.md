## 一、操作

### 手机（主要目标平台）

| 手势 | 位置 | 效果 |
|---|---|---|
| 按住拖动 | 屏幕左半 | 浮动摇杆，推的方向即行进方向，推得越远走得越快 |
| 快跑按钮 | 屏幕右下 | 点亮切换快跑（摇杆幅度照常控速度），再点熄灭 |
| 视角按钮 | 屏幕右上 | 三档循环：第一人称 → 第三人称 → 自由，按钮上写着当前是哪一档 |
| 正交按钮 | 视角按钮下方（仅自由视角出现） | 切换 透视 ⇄ 正交，点亮表示当前是正交 |
| 双指开合 | 屏幕右半（仅自由视角） | 缩放镜头，1.5 – 60 m。可以一边推摇杆走一边缩，互不干扰 |
| 按住拖动 | 屏幕右半 | 转视角，左右转动、上下俯仰 |
| 轻点 | 屏幕右半 | 跳跃（带轻微振动反馈） |

- 摇杆**落指即生成**，不固定在某个位置，按哪里哪里就是原点。
- 左右手可同时操作：左手推摇杆走，右手转视角（三种视角都支持，包括自由视角）。
- 「转视角」和「跳跃」共用右半屏，靠手势区分：移动超过 11px 算拖动，按下不到 280ms 又没移动才算轻点。

### 键盘鼠标

| 输入 | 效果 |
|---|---|
| `W A S D` / `↑ ← ↓ →` | 移动（相对相机方向） |
| `Shift`（按住） | 快跑，6.5 m/s |
| `空格` | 跳跃 |
| 拖动鼠标 | 转视角 |
| `V` | 切视角（第一 → 第三 → 自由） |
| 滚轮 | 自由视角下缩放镜头，1.5 – 60 m |
| `O` | 自由视角下切 透视 / 正交 |
| `Q` / `E` | 转视角（不用鼠标时的备选） |

## 二、角色

一个灰色的人形，用的是 ALS（Advanced Locomotion System）原版的 AnimMan 网格，身高 1.83 米。

### 数值

| 项 | 值 | 说明 |
|---|---|---|
| 身高 | 1.80 m | 脚底到头顶，约 7 头身 |
| 关节 | 膝 0.46 m / 胯 0.90 m / 肩 1.40 m | 四根肢体均为两节 + 关节 |
| 移动速度 | 4.5 m/s | 跑步速度；推到一半摇杆会降为走路（约 1.7 m/s 以下为走） |
| 快跑速度 | 6.5 m/s | Shift 按住（键盘）/ 快跑按钮点亮（手机）；播 ALS 原版冲刺动画 |
| 加速度 | 20 m/s²（恒定） | UE 式恒定加速度，起步约 0.22 秒到全速，松手同样速率停下 |
| 重力 | 21 m/s² | 比真实重力大，落地更干脆 |
| 跳跃初速 | 6.7 m/s | **跳起高度约 1.07 m**，略高于自身一半 |
| 滞空时间 | 约 0.64 s | 上升 0.32s + 下落 0.32s |
| 转向速度 | 12（弧度/秒的插值系数，v0.11.8 起随速度降到 8） | 冲刺转弯带惯性弧线 |

### 状态与动作

| 状态 | 表现 |
|---|---|
| 站立 | 轻微呼吸起伏（躯干 1.2cm 上下），双脚前后错开约 10cm，膝盖微屈 |
| 走路 | 步幅小、手臂摆幅小、身体几乎直立 |
| 跑步 | 步幅大、手臂大幅摆动且肘部收得更紧、身体明显前倾、起伏更大 |
| 起跳 | 按起跳时的速度分两种：普通走/跑用走跳（双臂前摆到下巴），快跑中用跑跳（原版单脚发力、反侧手甩起）；左右脚每次交替 |
| 空中 | 上升段延续起跳的腿部动作，到最高点转为下落姿势（双腿收起、身体微蜷），**空中不踏步** |
| 起步 / 急停 | 身体按加速度前后倾斜：起步前压，松手后仰 |
| 落地 | 跑跳落地（还带着速度）不插入落地姿势，跑步继续、身体压一下；原地或慢速落地才播完整的蹲身缓冲 |
| 跳跃 | 输入缓冲 0.14s：空中按跳，落地瞬间自动起跳（v0.11.8） |
| 落地镜头 | 相机随落地冲击微沉后弹回（v0.11.8） |
| 转弯 | 身体按横向加速度向内侧倾斜 |
| 冲刺镜头 | FOV +4°、相机拉远 0.7m（v0.11.8） |
| 靠近积木/高塔 | **第三人称**：相机自动拉近（最短 0.9m），走开缓缓恢复；**自由视角**：机距不动，挡住视线的东西变半透明，走开恢复 |

### 音效

用的是 **ALS 项目里的原版混凝土脚步录音**（内嵌在文件里，不依赖外部资源）。第一次点屏幕或按键盘时启用。

如果右下角出现「🔇 点这里开声音」，说明浏览器还没放行音频，点它一下即可。iPhone 记得把侧边静音拨片关掉。

| 声音 | 什么时候响 | 用什么 |
|---|---|---|
| 脚步 | 走/跑/冲刺时，按动画里真实的脚触地时刻 | 走用 `Concrete_Walk`（5 个变体）、跑用 `Concrete_Run`（4 个变体），每次随机换一个并微调音高 |
| 跳跃 | 起跳瞬间 | `Concrete_Step`（ALS 原版跳跃也是播脚步） |
| 落地 | 触地瞬间 | `Concrete_Step`，冲击越大越响 |

地面是白色荒原，所以用"混凝土"那一套录音，不是沙地或草地。

所有形变都是指数回弹，不做关键帧。

## 三、世界元素

| 元素 | 数量 | 分布 | 作用 |
|---|---|---|---|
| 地面 | 1 片 | 300 × 300 m | 行走平面，白色 |
| 大积木 | 72 块 | 距原点 11–87 m 随机 | 空间参照物，部分高 2.5–5.3 m |
| 小散石 | 240 颗 | 距原点 1.6–43 m | 近景细节，提供移动速度感 |
| 远处高塔 | 11 座 | 距原点 42–88 m，高 6–15 m | 撑开世界尺度，雾中地标 |
| 郊区住宅 | 1 栋（主屋 + 车库 + 门廊 + 车道 + 小院） | 出生点正前方 9–24 m | 第一个"有人住过"的东西；院子 16 × 15 m，两棵树 |

- 分布由固定种子的伪随机决定，**每次打开世界完全一样**。
- 积木和高塔有实体（挡人、能站），散石只是装饰、可以直接踩过去。全部不可拾取、不可破坏。

## 四、空间与视角

- 三种视角，开的就是**自由**（能看见整片地方），用右上角「视角」按钮（桌面按 `V`）循环：自由 → 第一 → 第三。默认不再是第三人称——出生点旁边就有一栋房子，第一眼该看见它，而不是角色后脑勺。
  - **第一人称**：眼睛高度 1.62 m，拖动上下抬头/低头，走动方向永远朝视线前方。
  - **第三人称**：绕角色的轨道，镜头在肩膀高度（不是胸口，所以贴近看也不会卡在肚子上）。可 360° 水平旋转，俯仰 3°–57°，距离固定不缩放。
  - **自由**：进来先给一个高位全景——俯角约 38°、机距横屏 23 m / 竖屏 20 m（就是以前俯视档的取景），镜头会在半秒内平滑滑过去，你一动它就停。之后什么都自己定：拖动随便转（能一直翻到头顶、翻到脚底），滚轮 / 右侧双指开合把镜头从 1.5 m 拉到 60 m——最近停在肩膀高度，再近就钻进身体了。
    - 这一档还有个「透视 / 正交」按钮（桌面按 `O`）：正交是平行投影，远近一样大，适合看布局和比例；透视就是我们平时看世界的近大远小。缩放的手感两档一样。
  - 三种视角之间都是连续过渡，不是硬切。
- 地面有一层很淡的网格（1 m 细线、5 m 粗线），只用来看距离和尺度，远处会自动淡掉。
- **方块有实体**：正面撞上去会停住，斜着撞会贴着墙蹭一点再停下（30° 以内基本顶死，更斜才滑得动）；能跳上 1 米左右的方块并站在上面走，站在上面能看清周围；走出边缘会掉下去。
- 落差 0.35 m 以内的小坎自动迈上去，不用跳；更高的必须跳（跳跃上限约 1.07 m）。
- 世界没有边界：地面跟着角色走，雾在 145 m 处已经把一切吞成白色，走不出去也看不到边。
- **出生点正前方有一栋房子**：一层、坡屋顶、带车库和栅栏小院，门廊前有三条台阶。院子四边围着 0.95 m 高的木栏，南面留了车道口和院门两个缺口——从车道口能一路走进院子、走到车库门前。房子有实体（撞墙会停），门和窗是深色面片，暂时不能开。
- **出生点正前方还有一条测试台阶**（三级 0.3 m + 一个 0.9 m 平台）：直走就能一级级走上去，走到平台边缘会掉下来。这是用来试碰撞的临时道具，不算世界的一部分。

## 五、当前版本能做什么

- 在一片白色荒原上自由行走、转身、跳跃。
- 转视角观察四周，环境里的方块与散石提供方向和距离感。
- 仅此而已。没有目标、没有敌人、没有可拾取物、没有存档。

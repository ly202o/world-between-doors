- 走出大落差边缘保留55%水平速度，空中0.70/s阻尼/16%操控，落地按冲击分级吸收。烟囱、门廊柱已加入碰撞；树冠/薄窗/小散石/灌木保持装饰。

### 手枪（v0.13.0 重做）

- 左键 / 手机「射击」按钮每次按下一发（半自动）；R 或「换弹」装填。**12 发弹匣 / 72 发备弹**，射击间隔 **0.14 秒**，换弹 **1.35 秒**（分抬枪、下沉、退匣、上匣、回位四段，中段补弹）。
- **准星会张合**：站着不动最紧，跑动、腾空、连续开火都会变大——它同时就是真实散布，张多大就可能偏多远。命中变金色，没子弹变红色。
- **空仓**：不会静默失败。枪会干击顿挫一下，准星变红，底部提示「空仓 · 按换弹」。
- 每一发都有：滑套后座、枪口火光与烟、弹壳抛出落地、曳光、命中处的弹孔（会停留几秒后淡出）。打靶时靶面会闪一下并计数。
- 第一人称按视线射击，第三/自由按相机水平朝向射击；准星表示射线前方 12m 投影，近远距离有视差。点画面射击同时请求鼠标锁定；拒绝锁定仍可按住拖动转视角。右键不射击。
- 出生点右前方 (4 / 5.8 / 7.6, 1.35, -6) 有 3 块几何靶；场景实体会挡子弹。靶子仅训练反馈，不挡走路、无生命/敌人系统。
- 攀爬期间不能开火或开始换弹；设置面板打开时不能射击。手机射击/换弹按钮不占用右侧转视角手指。
- **有枪声了（v0.13.1）**：开火是三层叠出来的枪响（低频冲击 + 爆裂 + 尾音），干击、退匣、上匣各有一下金属声。脚步声更响还是枪声更响是量过的：枪声峰值大约是脚步的 1.2 倍。
- **只有一把枪（v0.13.1）**：第一人称和第三人称用的是同一把。第一人称不是另做一套枪模，而是把持枪的手臂抬到眼前——枪落在画面右下角，和第三人称那只手是同一只手。
- **第三人称能看见枪**：站定时身体会自然侧偏约 29°（真实的射击站姿），枪从右肩前露出来；从正后方也不会被躯干挡住。
- **环境音**：风里带鸟叫，一条 9 秒的循环，一开声音就有，慢慢淡进来。声音开关没有单独做，静音跟着浏览器/系统走。
- **转身步（pivot）**：跑起来之后把方向拧过大约 120°，脚下会"碾"一下——这是 ALS 原版的转身脚步录音，站着急转不会触发。

### 侧栏能一边开一边玩 / 碎石有碰撞 / 出生点土坡（v0.13.6）

- **清单拉开着也能操作**：不用先把侧栏收起来。拖画面转视角、走路、开枪都照常，侧栏就挂在那儿。勾完点「收起」或按 Esc 走。
- **地上的碎石现在会挡人了**：小的会被自动踩过去（腿抬一下），石头高过一台阶就真的挡。以前是从石头中间穿过去。
- **绕着树走不会磕到看不见的角**：树干换成圆的碰撞，贴着树干转一圈距离都一样。
- **出生点往东两步有个小土坡**（约 20°），专门用来试"脚有没有真的踩在斜面上"。以前要看这个得爬上屋顶。
- **环境音（风 / 鸟叫）默认关了**。想听就 F2 打开设置，勾「环境音」。开枪、脚步、按钮音不受影响。

### 右栏清单 / 默认静音（v0.13.5）

- **屏幕右缘有一条竖着的小标签「清单」**，点它从右边拉出一整条侧栏。里面是这一路的每次改动，可以一条条勾。点「收起」或按 Esc / F3 收回去。
- **每条有四个动作**：通过、不通过、**待办**、反馈。待办是给"现在能用、但后期还要改或有设想"留的位置——它不混进通过里，欠的账不会消失。下面还有一栏写整体感受，写完全部勾选能一键复制成一段文本。
- **勾过的会记在这台设备上**，刷新、关掉再开都还在。
- **打开页面不再先响一声**：默认静音。左下角写着「🔇 静音」，点它就开声音；侧栏顶部也有同一个开关。选择会记住。

### 头会看（v0.13.4）

- **边走边转视角，角色会先转头看过去**，身体继续朝走的那个方向。往回走时回头看一眼的样子，就是这里来的。
- 头最多转约 65°。超过这个角度身体会自己转过去，不会拧着脖子走。
- 站着不动时身体为了让枪露出来会侧着站（约 29°），**脸是正的、朝着你看的方向**——就是瞄准时的站姿。
- 第一人称看不到自己的头，所以这个不影响第一人称。

### 脚贴地（v0.13.3）

- **站在斜屋顶上，两只脚都真的踩在坡面上**，不再一只悬空、一只陷进去。鞋底会顺着坡倾斜。
- 台阶边缘、门口台阶、石头顶上同理：脚跟着地面走，不会半只脚穿进地里。
- 落地的瞬间身体会沉一下把体重压上去，然后稳住——不是硬邦邦地悬在半空。
- 走动时脚按动画正常摆，不会被"粘"在坡上滑。
- 站着不动时身体会有极轻微的起伏（呼吸），但脚是钉在地上的，不会跟着浮。

### 原地转身（v0.13.2）

- 站着不动、把视角转到身体侧面或身后，角色会**真的转身**——迈步、碾脚、带一声脚步，不是原地把模型转个角度。
- 转身有明确的角度上限（一次 90°）。需要转更大的角度时会连着转。
- 边走边转视角不会触发转身：走路时身体跟着移动方向，那是另一套逻辑。
- 甩视角看风景时身体不会跟着乱转，等你停下来才转过去。

### 界面音（v0.13.1）

- 点按钮有一声轻响（ALS 原版 UI/Click）。只在真的点到按钮时响，点画面射击不会。

### 画质自适应（v0.13.0）

- 手机上默认：关闭抗锯齿、渲染像素比封顶 1.5、阴影 1024。桌面维持 2 倍像素比 + 抗锯齿 + 2048 阴影。
- 帧率撑不住时会**自动降低渲染分辨率**（最低到 0.62 倍），画面会轻微变软，但操作和动作速度不受影响；环境恢复后会自己爬回来。
- 判断依据：帧率持续低于约 43 FPS 就降，稳定高于约 56 FPS 才回升。

### 输入审查修复（v0.11.45）

- 切后台/失焦会清理键鼠、摇杆、视角手势、捏合与待执行跳跃，回来不继承按住状态。取消触摸不算轻点跳跃；设置期间画面输入不改变相机。

### 基础移动补齐（v0.11.44）

- 栅栏按真实柱/横板碰撞，靠近按跳是**翻越**：落点是另一侧地面，不会站在 0.1m 宽的板顶上。主屋和车库坡屋面可承接落地、沿坡行走；门廊雨棚下起跳会撞头。门窗仍不能开。
- 攀爬分两档：1.30m 以内约 1.05 秒（跑撞会自动上），1.30–2.35m 约 1.55 秒、**要站到墙前按空格**（用的是 ALS 原版 1m / 2m Mantle 动作，位移跟着动作的根骨曲线走，所以身体和脚同步，不会打滑）。前进跳向近处高沿可自动抓住，空中按跳也先尝试抓沿；超过 2.35m 的墙（比如主屋 3m 墙）够不到，只能跳。
- 快跑撞到矮沿（≤1.30m）会攀爬；撞到可攀的高墙只是停住，按空格再上；撞到不可攀的墙（3m 主屋、灌木、靶子）只短促踉跄/减速一次，不长期锁定移动。踉跄使用已有落地动作加代码前倾，不是专用新动画。
- 自动迈阶上升3.6m/s、下降2.8m/s，不再单帧跃升0.30m。双脚接触检测和骨盆补偿属于初步适配，并非完整脚IK，脚掌还不随坡面旋转。
- 碰撞模式颜色：绿实体、橙栅栏、粉坡面、蓝玩家移动圆柱、金跟骨骼近似盒。金盒仅显示，不改变移动阻挡，不是骨骼物理。设置里可看攀爬阶段、抓沿命中、撞墙类别、踉跄时间、左右脚接触与骨盆补偿。
- 武器现已按用户本次授权实现最简半自动手枪，见上方；完整腿IK、手掌抓沿、骨骼物理仍不是当前能力。

### 运行调试 / 设置（v0.11.43）

- 第三/自由视角下身体按输入目标方向转身，正面顶墙速度归零也能转回前方；第一人称仍跟视线。
- 栅栏 v0.11.44 已改逐构件碰撞并支持薄顶攀爬；见上方基础移动补齐。

## 二、角色

一个灰色的人形，用的是 ALS（Advanced Locomotion System）原版的 AnimMan 网格，身高 1.83 米。

### 数值

| 项 | 值 | 说明 |
|---|---|---|
| 身高 | 1.80 m | 脚底到头顶，约 7 头身 |
| 关节 | 膝 0.46 m / 胯 0.90 m / 肩 1.40 m | 四根肢体均为两节 + 关节 |
| 移动速度 | 4.5 m/s | 跑步速度；推到一半摇杆会降为走路（约 1.7 m/s 以下为走） |
| 快跑速度 | 6.5 m/s | Shift 按住（键盘）/ 快跑按钮点亮（手机）；播 ALS 原版冲刺动画 |
| 加速度 | 20 m/s²（恒定） | UE 式恒定加速度，起步约 0.22 秒到全速，松手同样速率停下 |
| 重力 | 21 m/s² | 比真实重力大，落地更干脆 |
| 跳跃初速 | 6.7 m/s | **跳起高度约 1.07 m**，略高于自身一半 |
| 滞空时间 | 约 0.64 s | 上升 0.32s + 下落 0.32s |
| 转向速度 | 12（弧度/秒的插值系数，v0.11.8 起随速度降到 8） | 冲刺转弯带惯性弧线 |

### 状态与动作

| 状态 | 表现 |
|---|---|
| 站立 | 轻微呼吸起伏（躯干 1.2cm 上下），双脚前后错开约 10cm，膝盖微屈 |
| 走路 | 步幅小、手臂摆幅小、身体几乎直立 |
| 跑步 | 步幅大、手臂大幅摆动且肘部收得更紧、身体明显前倾、起伏更大 |
| 起跳 | 按起跳时的速度分两种：普通走/跑用走跳（双臂前摆到下巴），快跑中用跑跳（原版单脚发力、反侧手甩起）；左右脚每次交替 |
| 空中 | 上升段延续起跳的腿部动作，到最高点转为下落姿势（双腿收起、身体微蜷），**空中不踏步** |
| 起步 / 急停 | 身体按加速度前后倾斜：起步前压，松手后仰 |
| 落地 | 跑跳落地（还带着速度）不插入落地姿势，跑步继续、身体压一下；原地或慢速落地才播完整的蹲身缓冲 |
| 跳跃 | 输入缓冲 0.14s：空中按跳，落地瞬间自动起跳（v0.11.8） |
| 落地镜头 | 相机随落地冲击微沉后弹回（v0.11.8） |
| 转弯 | 身体按横向加速度向内侧倾斜 |
| 冲刺镜头 | FOV +4°、相机拉远 0.7m（v0.11.8） |
| 靠近积木/高塔 | **第三人称**：相机自动拉近（最短 0.9m），走开缓缓恢复；**自由视角**：机距不动，挡住视线的东西变半透明，走开恢复 |

### 音效

用的是 **ALS 项目里的原版混凝土脚步录音**（内嵌在文件里，不依赖外部资源）。第一次点屏幕或按键盘时启用。

如果右下角出现「🔇 点这里开声音」，说明浏览器还没放行音频，点它一下即可。iPhone 记得把侧边静音拨片关掉。

| 声音 | 什么时候响 | 用什么 |
|---|---|---|
| 脚步 | 走/跑/冲刺时，按动画里真实的脚触地时刻 | 走用 `Concrete_Walk`（5 个变体）、跑用 `Concrete_Run`（4 个变体），每次随机换一个并微调音高 |
| 跳跃 | 起跳瞬间 | `Concrete_Step`（ALS 原版跳跃也是播脚步） |
| 落地 | 触地瞬间 | `Concrete_Step`，冲击越大越响 |

地面是白色荒原，所以用"混凝土"那一套录音，不是沙地或草地。

所有形变都是指数回弹，不做关键帧。

## 三、世界元素

| 元素 | 数量 | 分布 | 作用 |
|---|---|---|---|
| 地面 | 1 片 | 300 × 300 m | 行走平面，白色 |
| 大积木 | 72 块 | 距原点 11–87 m 随机 | 空间参照物，部分高 2.5–5.3 m |
| 小散石 | 240 颗 | 距原点 1.6–43 m | 近景细节，提供移动速度感 |
| 远处高塔 | 11 座 | 距原点 42–88 m，高 6–15 m | 撑开世界尺度，雾中地标 |
| 郊区住宅 | 1 栋（主屋 + 车库 + 门廊 + 车道 + 小院） | 出生点正前方 9–24 m | 第一个"有人住过"的东西；院子 16 × 15 m，两棵树 |

- 积木和高塔有实体（挡人、能站），散石只是装饰、可以直接踩过去。全部不可拾取、不可破坏。

## 四、空间与视角

- 三种视角，开的就是**自由**（能看见整片地方），用右上角「视角」按钮（桌面按 `V`）循环：自由 → 第一 → 第三。默认不再是第三人称——出生点旁边就有一栋房子，第一眼该看见它，而不是角色后脑勺。画面默认是深色主题，按 `T`（或手机「深色」按钮）能切回原来的白色世界。
  - **第一人称**：眼睛高度 1.62 m，拖动上下抬头/低头，走动方向永远朝视线前方。
  - **第三人称**：绕角色的轨道，镜头在肩膀高度（不是胸口，所以贴近看也不会卡在肚子上）。可 360° 水平旋转，俯仰 3°–57°，距离固定不缩放。
  - **自由**：进来先给一个高位全景——俯角约 38°、机距横屏 23 m / 竖屏 20 m（就是以前俯视档的取景），镜头会在半秒内平滑滑过去，你一动它就停。之后什么都自己定：拖动随便转（能一直翻到头顶、翻到脚底），滚轮 / 右侧双指开合把镜头从 1.5 m 拉到 60 m——最近停在肩膀高度，再近就钻进身体了。
    - 「45° / 俯仰」按钮（桌面按 `L`）锁死整个取景——僵毁那类等距生存游戏的相机本来就不跟着角色转。锁上之后上下、左右都转不动，朝向停在按下那一刻（不跳镜头；想换方向先解锁转好再锁），只有机距还能缩。再点一次解锁。
  - 三种视角之间都是连续过渡，不是硬切。
- 地面有一层很淡的网格（1 m 细线、5 m 粗线），只用来看距离和尺度，远处会自动淡掉。
- **方块有实体**：正面撞上去会停住，斜着撞会贴着墙蹭一点再停下（30° 以内基本顶死，更斜才滑得动）；能跳上 1 米左右的方块并站在上面走，站在上面能看清周围；走出边缘会掉下去。
- 落差 0.35 m 以内的小坎自动迈上去，不用跳；更高的必须跳（跳跃上限约 1.07 m）。
- **攀爬（v0.11.44）**：地面前方0.40–1.30m高的合适沿可撑上，包括薄栅栏；使用 ALS 原版 1m Mantle（约 1.05 秒）；1.30–2.35m 用 2m Mantle（约 2.1 秒）。空中抓沿与冲刺撞墙规则见上方增量；三米墙仍不可地面直接攀爬。
- 世界没有边界：地面跟着角色走，雾在 145 m 处已经把一切吞成白色，走不出去也看不到边。
- **出生点正前方有一栋房子**：一层、坡屋顶、带车库和栅栏小院，门廊前有三条台阶。院子四边围着 0.95 m 高的木栏，南面留了车道口和院门两个缺口——从车道口能一路走进院子、走到车库门前。房子有实体（撞墙会停），门和窗是深色面片，暂时不能开。
- **出生点正前方还有一条测试台阶**（三级 0.3 m + 一个 0.9 m 平台）：直走就能一级级走上去，走到平台边缘会掉下来。这是用来试碰撞的临时道具，不算世界的一部分。

## 五、当前版本能做什么

- 在一片白色荒原上自由行走、转身、跳跃。
- 转视角观察四周，环境里的方块与散石提供方向和距离感。
- 仅此而已。没有目标、没有敌人、没有可拾取物、没有存档。

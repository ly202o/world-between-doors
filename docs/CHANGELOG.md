## v0.8.0 — 2026-11-13

**角色换成 ALS 原版 AnimMan 的真实网格**

不再是几何体拼的。直接把 ALS 项目里 `AnimMan.uasset` 的网格拿出来做角色。

### 怎么拿到的

`.uasset` 里的顶点是 16 位压缩存储，纯解析拿不到。改用本机的 **UE 5.8 命令行**导出：

```
UnrealEditor-Cmd.exe <project> -ExecutePythonScript="export_meshes.py" -unattended -nosplash
```

脚本里调 `unreal.SkeletalMeshExporterFBX()`。注意：`-run=pythonscript`（commandlet 模式）会因为没有渲染资源触发 `MeshObject` 断言崩溃，必须用 `-ExecutePythonScript` 让编辑器完整启动。

### 新增

- 角色网格：AnimMan，10269 顶点 / 16544 三角面 / 68 根骨骼。
- 用 FBX 的 Skin Cluster（顶点索引 + 权重）做刚性绑定：每个顶点归给权重最大的骨骼，按 15 个部位分组，各挂一根 pivot，沿用原来的走跑落动画。
- 手臂从 A-pose 转成自然下垂（外层 `rotation.z` 修正 0.66 弧度，内层做摆动）。

### 变更

- `index.html` 从 690 KB 涨到 **1.12 MB**（多出 417 KB 角色数据）。
- 材质仍是哑光灰，`#8f93a8`。

### 未做 / 已知问题

- 刚性绑定导致关节处有分块接缝：躯干能看到胸 / 腹 / 胯三块的边界，腿臂同理。真正的平滑需要骨骼蒙皮（`SkinnedMesh` + 权重插值），当前是每块独立刚体。
- 脚部没有落地 IK，踩地时可能轻微穿插。

## v0.7.0 — 2026-11-13

**用 SK_Mannequin 的原始 FBX 顶点数据校准了角色比例**

不再靠截图目测。下载了 Epic 官方的 `SK_Mannequin.fbx`（`refs/SK_Mannequin.fbx`），写脚本解析二进制 FBX 取出 20719 个顶点，按高度分带量出每一层的宽/厚，据此重排角色。

### 实测数据（原生身高 182.5 cm）

| 高度 | 部位 | 宽 | 厚 |
|---|---|---|---|
| 90 cm | 胯 | 38.0 | 26.0 |
| 110 cm | 腰 | 29.6 | 20.5 |
| 135 cm | 胸 | 39.7 | 32.2 |
| 150 cm | 肩 | 38.9 | — |
| 162–182 cm | 头 | 17.8 | 16.0 |

腿：大腿直径 17 cm、膝下 14 cm、小腿中段 10 cm、脚踝 7.6 cm。

### 修正

对照下来，之前三处偏差很大：

- **躯干太薄**：厚度只有 23 cm，实际 32 cm —— 这是它看起来像纸片人的主因。`scale.z` 由 0.64 提到 0.80。
- **胯部太窄**：25 cm，实际 38 cm。躯干旋转体的下半段半径由 0.158 加到 0.185。
- **小腿太粗**：直径 13 cm，实际 10 cm。半径由 0.067 收到 0.056。

另外把肩部收窄到 0.126（此前 0.155 把手臂整个吞进躯干里），肩线才显出来。

### 新增

- `refs/SK_Mannequin.fbx`：原始参考模型，仅开发时对照用，不参与运行。
- FBX 二进制解析脚本（临时，已清理）：手工解析 Node Record 结构，zlib 解压属性数组，提取 `Objects/Geometry/Vertices`。

## v0.6.0 — 2026-11-13

**照着 ALS-Community 的 C++ 源码复刻了动作系统**

参考项目：[dyanikoglu/ALS-Community](https://github.com/dyanikoglu/ALS-Community)（Advanced Locomotion System V4 的 C++ 社区移植版）。

### 新增

- **加速度倾斜（Lean）**：直接移植 `CalculateRelativeAccelerationAmount()` 的思路——把世界坐标下的加速度按角色朝向反旋转到局部，前后分量驱动 `leanFB`、左右分量驱动 `leanLR`，再用 `GroundedLeanInterpSpeed` 做指数平滑。效果是起步前压、急停后仰、转弯侧倾。
- 脚掌水平补偿：跑动时脚不再是跟着小腿"踢"，而是相对地面保持水平。

### 变更

- **移动模型由指数趋近改为恒定加速度**（20 m/s²）。UE 的 `CharacterMovement` 就是恒定加速度，这样加速度有持续时长，倾斜系统才跟得上；指数趋近的加速度是脉冲式的，倾斜刚起来就衰减了。
- 角色形体重做：躯干改用 `LatheGeometry` 一条轮廓线扫出胸宽腰收臀阔；头由球改为竖胶囊（UE 的头是圆桶不是球）；面罩改成薄板；手由球改为方块。
- 四肢加粗到有分量的程度（上臂 r0.057、大腿 r0.098），此前像面条。

### 参数来源

| 参数 | 值 | 出处 |
|---|---|---|
| `GroundedLeanInterpSpeed` | 4.0 | `ALSAnimationStructLibrary.h` |
| 动画基准速度 | 走 150 / 跑 350 / 冲刺 600 cm/s | 同上 |
| 加速度 | 20 m/s² | UE 默认 `MaxAcceleration` 2048 cm/s² |

倾斜响应实际用了 6.0 而非 4.0，因为本项目的加速时间（0.22 s）比 UE 短，4.0 跟不上。

### 未做

- 模型几何：ALS 的 `SK_Mannequin` 是 `.uasset` 二进制资产，C++ 源码里没有顶点数据，只能按形态逼近。
- 冲刺档、原地转身、攀爬、翻滚：ALS 有，本项目还没做。

## v0.5.0 — 2026-11-13

**角色改为 UE 白模风格，动作接入走 / 跑 / 落地三态**

### 新增

- 角色重做为 UE Mannequin 白模：哑光灰 `#8b8f95`、分块装配、无贴图，肩部有三角肌隆起。
- 走路与跑步两套步态按速度自动混合：1.7 m/s 以下纯走，3.6 以上纯跑。
- 落地缓冲：按落地冲击决定下蹲深度，膝盖屈曲、躯干前压、手臂前甩。
- 最大移动速度由 3.6 提到 4.5 m/s。

### 变更

- 躯干拆成胸廓 / 腹 / 骨盆三段椭球，靠形体本身做人体轮廓，不再是一根胶囊。
- 手臂加长到接近真人比例（肩到指尖约 0.54 m），肘部改为向前弯（此前方向写反，跑起来像僵尸手）。
- 大腿补满到膝关节，消除跑动时膝部露出的断裂缝。
- 站姿加宽、三角肌外移，修背面视角两腿与双臂糊成一团的问题。
- 身高 1.86 → 1.80，头身比由 5.7 调整为更接近真人的 7 头身。

### 未做

- 冲刺档位（需要额外按键或手势，尚未和用户确认）。
- 转向、蹲伏、翻滚等 ALS 的其余动作组。

## v0.4.0 — 2026-11-13

**角色重做：分节骨骼，有膝盖和肘**

### 新增

- 角色改为分节骨骼：髋→大腿→**膝**→小腿→脚、肩→上臂→**肘**→前臂→手，关节处补球体避免弯折破面。
- 走路动画由「整条腿绕髋旋转」改为「髋摆 + 膝弯 + 脚掌补偿」，出脚时屈膝、落步时伸直的步态成立。
- 补了鼻部凸起，侧面终于能看出朝向。
- 行走时重心左右转移（躯干 0.034 弧度侧倾），不再是水平滑行。

### 变更

- 身体比例按真实人形重排：脚底 0 · 踝 0.08 · 膝 0.48 · 髋 0.95 · 肩 1.42 · 头顶 1.86。
- 躯干由「一根胶囊」拆为胸廓 + 髋部两段，中间收腰；肩部胶囊加宽到略超躯干，背面才有肩线。
- 头部上抬并加颈（此前头陷进躯干里，看起来像没有脖子）。
- 站姿加宽到 ±0.125，修复背面视角两腿重叠成一条的问题。
- 脚掌缩小约 25%，此前像踩着两块砖。
- 空中姿态：手臂改为向后甩（原先是抬在胸前，像抱着东西），双腿屈膝并略微分开。

### 未做

- 侧面剪影仍偏「柱状」，缺少胸腔与骨盆的前后错落。
- 没有面部（单独一个鼻凸），当前风格下够用。

## v0.3.0 — 2026-11-13

**相机改为绕角色的轨道，支持转视角**

### 新增

- 手柄/鼠标/触摸三种方式转视角：手机右半屏拖动、桌面拖动鼠标、键盘 `Q` `E`。
- 相机改为球面轨道（yaw / pitch / dist 三个量），可 360° 水平环绕、3°–57° 俯仰。
- 右半屏「转视角」与「跳跃」共用：移动超过 11px 判为拖动，短按原位松开判为跳。

### 修正

- **移动方向改为相机相对**。此前转完视角按 `W` 仍然朝旧方向走，与世界朝向脱节。
- 远处空无一物、转身后没有纵深：大积木由 46 块扩到 72 块并铺到 87 m，散石 150 → 240 颗铺到 43 m，雾色压深至 `#F1F5F8`，地平线重新可见。
- yaw 每帧归一化到 ±2π，避免长时间旋转后浮点精度下降。

### 未做

- 松手自动回正：待决策（会牺牲自由视角手感）。
- 移动端右半屏手势的成功率未在真机上实测（headless 触摸已通过）。

## v0.2.1 — 2026-11-13

**修复手机上打开纯白**

### 修正

- 根因：`index.html` 通过 `<script src="vendor/three.min.js">` 引用引擎，只把 html 传到手机时依赖目录没跟着走，`THREE` 未定义，脚本首行即中断，canvas 全白且无任何提示。
- Three.js 整段内联进 html，文件变为自包含单文件（约 690 KB）。
- 内联时删掉库首行 `console.warn(...)` 导致紧跟的立即执行函数落到语句开头、被解析为无名函数声明而报错，已改用 `!` 前缀修复。

### 新增

- 启动自检层：引擎未加载 / WebGL 未启用 / 渲染器初始化失败 / 3.5 秒未出第一帧，四种情况均在屏幕中央显示中文原因，不再白屏。

### 变更

- 验证方式改为「孤立目录测试」：新建空目录、只放一个 html、headless 截图。

## v0.2.0 — 2026-11-13

**二维横版重构为三维世界**

### 新增

- Three.js 渲染的 3D 白色荒原：白地面、白天空、雾化地平线。
- 72 块白色积木、240 颗实例化散石、11 座远处高塔（初版为 46 / 150 / 11）。
- 方向光长投影（约 1.5 个身位），是白色场景里的主要形状信息。
- 角色改为 3D 几何体拼装：球头、颈、肩、胶囊躯干、四根可旋转肢体，带走路步态、起跳拉伸、落地压扁。
- 竖屏 / 横屏分别配置 fov 与相机距离。

### 变更

- 操作轴改为二维（前后 + 左右），摇杆支持八方向模拟量。
- 原 2D 版本归档为 `flat.html`，不再维护。

### 备注

- 白色世界的光照容错极小：Three.js r155+ 物理光照下，各光源强度之和需到 3.0 量级地面才接近纯白。
- 阴影相机改范围后未调用 `updateProjectionMatrix()`，一度只有角色脚下有影子。

## v0.1.0 — 2026-11-13

**初始版本：二维剪影世界**

### 新增

- 单文件 Canvas 2D 横版原型：纯白天空、纯白地面、一条地平线。
- 侧视剪影角色，带走路步态、跳跃、起跳拉伸与落地压扁。
- 跳跃手感：0.12s 土狼时间、0.14s 输入缓冲。
- 双端操作：左半屏浮动摇杆 + 右半屏轻点跳；键盘 `A` `D` / `←` `→` + `空格`。
- 全局视觉缩放：竖屏 1.34 / 横屏 1.05，保证手机竖屏下角色占比不过小。
- 地面刻度线、远景低矮建筑带（视差 0.34）作为移动参照。

### 备注

- 角色首版误按正面视角绘制左右手臂，剪影呈火柴人；改为侧视结构（躯干填充 + 颈 + 前后明暗分层）后成型。

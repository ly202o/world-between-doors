# WORLD 01

一片白色的天，一片白色的地，一个人。

用代码造出来的极简世界原型 —— 没有一张图片素材，所有形体由几何体与光照构成。

**版本** v0.8.0 ｜ **形态** 单文件 HTML ｜ **平台** 手机 + 桌面

---

## 打开

双击 `index.html`，或拖进任意浏览器。

文件是自包含的（Three.js 已内联），离线可用，可以随便拷贝到手机上——**只要这一个文件，不需要旁边的任何东西**。

---

## 协作方式

这是长期项目，两个人一起造。

**有好想法先说出来，得到同意再做**，不擅自改世界规则、不顺手优化没被要求的东西。
规则写在 `docs/RULES.md` 第一节，接手前必读 `docs/MEMORY.md`。

---

## 操作

**手机**

| 手势 | 位置 | 效果 |
|---|---|---|
| 按住拖动 | 左半屏 | 移动（浮动摇杆，落指即生成） |
| 按住拖动 | 右半屏 | 转视角 |
| 轻点 | 右半屏 | 跳跃 |

**桌面**

| 输入 | 效果 |
|---|---|
| `W A S D` / 方向键 | 移动 |
| `空格` | 跳跃 |
| 拖动鼠标 | 转视角 |
| `Q` `E` | 转视角（不用鼠标时） |

## 目录

```
world01/
├── index.html          ← 主程序，单文件，唯一的交付物
├── flat.html           ← 第一版二维横版，已归档不再维护

├── docs/
│   ├── RULES.md        ← 章程与开发规则

│   ├── GAME.md         ← 游戏文档：操作、数值、世界元素、待办
│   ├── MEMORY.md       ← 项目记忆：背景、已定的决策、踩过的坑、参数速查
│   └── CHANGELOG.md    ← 更新说明
├── backups/            ← 每个版本的 html 快照（可直接双击回退）
└── tools/
    └── snapshot.sh     ← 一键快照：备份 + 校验 + 提交 + 打标签
```

## 发版

```bash
bash tools/snapshot.sh 0.4.0 "一句话说明这次改了什么"
```

会依次完成：备份 html 到 `backups/` → 逐块语法校验 → git 提交 → 打 tag。

发版前记得先补 `docs/CHANGELOG.md`。
